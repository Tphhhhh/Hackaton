Utiliser un vrai face swap avec Deep-Live-Cam

Lancez Deep-Live-Cam, choisissez votre portrait puis « Live ». Cliquez sur « Brancher Deep-Live-Cam » et partagez uniquement sa fenêtre d’aperçu. Le flux externe peut avoir un léger décalage. Le suivi facial est recalculé sur cette image.

Si la webcam est déjà utilisée, libérez-la dans l’autre application ou utilisez une source virtuelle OBS. Fermer le partage revient au filtre intégré.
