# Hackaton : détection des faux candidats à distance

Projet Secure Horizons (Open Track) : aider les ESN, sociétés de portage et plateformes de
freelances à repérer les embauches frauduleuses sous fausse identité (NIST CSF : Detect,
Respond, Govern).

- [`metadata/`](metadata/README.md) : cross-check des métadonnées des candidatures (CV,
  profils, coordonnées, connexions, paiement) et détection des réseaux de personas.
- Détection de deepfakes vidéo : module à venir.
